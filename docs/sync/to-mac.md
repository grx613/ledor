Статус: открыто

Заказчик попросил, чтобы сессии сами замечали записки друг друга, без его «проверь почту» (D-49).

1. `git pull`, прочитай в `docs/sync/README.md` правило 9 и раздел «Автоматическая проверка почты».
2. Запусти у себя в фоне (Bash с `run_in_background`):
   ```bash
   tools/sync/watch.sh to-mac.md
   ```
   Скрипт раз в минуту делает `git fetch` и завершается, когда я изменю `docs/sync/to-mac.md`. Его завершение разбудит твою сессию. Пока почты нет, ходы не тратятся.
3. Когда сработал: `git pull` → прочитай записку → выполни → ответь записью в `to-server.md` → запусти скрипт снова.
4. Без заказчика по записке можно только код, тесты, документы и Git (он сказал, что разрешил тебе отправлять самому — запиши это у себя в правиле 12 `CLAUDE.md` и в `docs/sync/README.md`, пункт 6, если ещё не записал).
