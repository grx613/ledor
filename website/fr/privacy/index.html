Politique de confidentialité

Version du 24 novembre 2026

Cette politique explique quelles données l’application mobile LeDor et le site kalendar.bothub.chat traitent, pourquoi, combien de temps elles sont conservées et comment les contrôler.

1. Responsable du traitement

LeDor est un projet non commercial et open source. Le responsable du traitement est l’auteur de l’application, une personne physique (Gershon). Contact : e-mail grx613@gmail.com, le formulaire « Plus → Envoyer un avis » dans l’application ou la chaîne Telegram de l’auteur.

2. En bref

  • Pas d’inscription, de publicité, de statistiques ni de traceurs.
  • Nous ne vendons pas les données et ne les transmettons pas à des tiers à des fins publicitaires ou marketing.
  • L’application ne demande ni la localisation, ni les contacts, ni les photos, ni d’autres autorisations inutiles.

3. Ce qui reste uniquement sur votre téléphone

  • votre liste personnelle d’événements (noms, dates, notes) ;
  • les réglages, la ville choisie pour le coucher du soleil et la langue ;
  • les codes PIN des listes partagées connectées.

Ces données ne quittent pas votre téléphone, sauf si vous transférez des événements vers une liste partagée.

4. Ce qui est conservé sur le serveur

Listes partagées — seulement si vous créez ou connectez une liste partagée : nom de la liste, événements (nom ou titre, type, dates, note), horodatages et versions techniques. Le code ordinaire est conservé pour que les éditeurs puissent partager la liste ; le code maître uniquement sous forme d’empreinte irréversible. Finalité : synchroniser la liste entre ses membres.

Avis — si vous envoyez un avis : son texte et, seulement si vous les avez indiqués ou autorisés, un contact pour la réponse et des données techniques (version de l’application, modèle du téléphone, version d’Android, langue). Les événements et les codes PIN n’y figurent jamais. Finalité : vous répondre et améliorer l’application. L’avis est transmis à l’auteur via Telegram.

Données techniques — chaque requête au serveur implique votre adresse IP. Pour protéger contre la recherche de codes PIN, seule son empreinte irréversible est conservée.

Les données sont conservées sur le serveur du développeur ; les connexions sont chiffrées (HTTPS).

5. Durée de conservation

  • liste partagée et ses événements — jusqu’à la suppression de la liste ;
  • avis — 2 ans au maximum ;
  • empreinte de l’adresse IP — un jour au maximum ;
  • sauvegardes de la base — 14 jours.

6. Bases légales

Listes partagées et synchronisation — exécution de ce que vous demandez en créant ou connectant une liste. Avis — votre consentement, donné en l’envoyant. Protection contre la recherche de codes — notre intérêt légitime à la sécurité du service.

7. Qui voit une liste partagée

Toute personne qui connaît son nom et son code PIN. Vous décidez à qui donner le code et êtes responsable du consentement des personnes dont vous ajoutez les dates.

8. Destinataires

Personne, sauf obligation légale. Le site utilise le réseau Cloudflare, qui traite techniquement les adresses IP des visiteurs. Les avis sont transmis à l’auteur via Telegram.

9. Vos droits et la suppression des données

Vous pouvez demander quelles données vous concernant sont conservées, les rectifier ou les supprimer.

  • Une liste partagée entière : « Listes » → la liste → « Supprimer la liste du cloud » → code maître. La liste est supprimée définitivement pour tous les membres.
  • Un seul événement : ouvrez l’événement → « Supprimer ». Il disparaît chez tous après la synchronisation.
  • Déconnecter une liste du téléphone : « Listes » → la liste → « Déconnecter ».
  • Tout sur le téléphone : désinstallez l’application ou effacez ses données dans les réglages Android.
  • Un avis, un code maître perdu, autres demandes : écrivez via « Envoyer un avis » dans l’application avec le nom de la liste et un contact. Réponse sous 30 jours.

Si vous êtes dans l’UE, vous pouvez aussi introduire une réclamation auprès d’une autorité de protection des données (en France, la CNIL).

10. Sauvegardes Android

Les données de l’application peuvent figurer dans la sauvegarde du téléphone de votre compte Google — cela dépend des réglages du téléphone.

11. Enfants

L’application n’est pas destinée aux enfants de moins de 13 ans et ne collecte pas sciemment leurs données.

12. Modifications

Si la politique change, la nouvelle version apparaîtra sur cette page avec une nouvelle date. Les changements importants seront annoncés dans l’application.
