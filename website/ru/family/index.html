Один календарь на всю семью

Вы с женой (или со всей семьёй) хотите видеть одни и те же даты: кто бы из вас ни добавил день рождения, он появится у обоих, и напоминание придёт на оба телефона. Для этого в LeDor есть общий список. Его видят только те, кому вы дали название и код.

  1. 1

    Откройте «Списки»

    На календаре или в «Событиях» нажмите «Списки» вверху справа. Там — ваш «Личный» список (он только на этом телефоне) и кнопки «Создать» и «Подключить».

  2. 2

    Создайте общий список

    Нажмите «Создать». Придумайте название — например, «Семья Коэн» — и два кода: ПИН-код для чтения (4–8 цифр, им можно только смотреть) и Мастер-ПИН (6–12 цифр, им можно добавлять и исправлять). Если в «Личном» уже есть даты, отметьте «Перенести события из личного списка».

  3. 3

    Поделитесь с родными

    Откройте созданный список. Чтобы жена тоже могла добавлять даты, включите «Поделиться правом редактирования» и нажмите WhatsApp или Telegram. Родственникам, которым достаточно смотреть, отправьте приглашение без этого переключателя.

  4. 4

    Родные подключают список

    Они устанавливают LeDor, открывают «Списки» → «Подключить» и вводят название списка и код из сообщения. Больше ничего не нужно: ни регистрации, ни почты.

  5. 5

    Готово — один календарь на всех

    Теперь всё, что добавляет любой из вас, видят все, и напоминания приходят на каждый телефон. Новые события сами попадают в общий список. Цветная метка показывает, из какого списка событие.

Частые вопросы

Кто ещё увидит наш список?

Никто. Список открывается только по названию и коду. Подбирать коды сервер не даёт: после нескольких ошибок попытки ограничиваются.

Чем отличаются два кода?

ПИН-код для чтения — смотреть даты и получать напоминания. Мастер-ПИН — ещё и добавлять, исправлять и удалять. Мастер-ПИН давайте только тем, кому доверяете.

При первом запуске приложение спросило про «импорт списка». Какой файл нужен?

Никакой. Это то же самое «Подключить»: если кто-то из родных уже создал общий список, введите его название и код. Если нет — нажмите «Нет» и создайте свой, как описано выше.

А если я не хочу ничем делиться?

Пользуйтесь «Личным» списком: он хранится только на вашем телефоне и никуда не отправляется.

Можно несколько списков?

Да: «Семья», «Община», «Друзья» — у каждого свой цвет и свои коды. Уведомления по каждому списку включаются отдельно.
