### 3. Те же исправления в приложении для iPhone

Образец — Android; если документ и код расходятся, прав код.

1. **Две строки для события «по обоим календарям».** В «Событиях» и в «Ближайших» на календаре — ближайшая дата по каждому календарю отдельной строкой, каждая со своим значком (✡ / ○) и своим «через N дней». Если две даты совпали — одна строка. Раньше показывалась одна ближайшая дата.
2. **У даты по григорианскому календарю — только григорианская дата.** Еврейскую дату того же дня не показывать нигде. У даты по еврейскому календарю — обе даты, как раньше.
3. **Карточка события.** При «по обоим» — два блока: «По григорианскому календарю» и «По еврейскому календарю», каждый со своей датой, «через N дней» и возрастом. В блоке григорианской даты — без еврейской даты.
4. **Редактор.** Строка «Ближайшее: …» под выбором календаря: для григорианской даты — без еврейской в скобках; при «по обоим» — две строки.
5. **Уведомление «в день события».** У наступления по григорианскому календарю текст — только григорианская дата и возраст. У еврейского — «{еврейская дата} · {григорианская дата}. {возраст}», как раньше.
6. **Перенос личного списка в облако (B-27).** В карточке личного списка кнопка «Перенести события в облачный список…» видна всегда, когда в списке есть события. Облачных списков с правом редактирования нет — открывается «Создать список» с включённым переносом. Есть — окно выбора: список или «+ Создать список»; после переноса открывается экран этого списка.
7. Исправление кнопки про экономию батареи (D-45) к iOS не относится.

Где смотреть:

- `docs/01-product-spec.md` — ALL-3 (правило дат и две строки), DET-1 (карточка), EVT-7 (редактор), LST-16 (перенос);
- `docs/DECISIONS.md` — D-46; `docs/05-reminders-battery.md`, таблица текстов уведомлений — строка DAY;
- код Android: `OccurrenceCalculator.nextEach` (`android/domain/.../event/Occurrences.kt`), `DateFormatters.occurrenceDates` (`android/app/.../ui/format/DateFormatters.kt`), `EventRow.kt`, `EventDetailScreen.kt`, `ListsScreens.kt`.

Пример для теста (из `DomainTest.observeBoth`): событие 23.04.1990 = 28 Нисана 5750, «по обоим», сегодня 24.11.2026 → две даты: 23.04.2027 (григорианская) и 05.05.2027 (28 Нисана 5787). Если сегодня 24.04.2027 → 05.05.2027 (еврейская) и 23.04.2028 (григорианская).
