# 07. Сайт

Сайт приложения: **https://kalendar.bothub.chat** (обновлено 2026-11-24). Задачи: представить LeDor, дать скачать
приложение, опубликовать политику конфиденциальности (её требуют магазины) и привлекать людей из поиска онлайн-конвертером дат.

## 1. Принципы

- Статический сайт без серверной части, куки, счётчиков, аналитики и внешних скриптов (не нужен и баннер согласия).
- Страницы **не пишутся руками**: их собирает `node tools/site/build.mjs` из одного шаблона и словарей
  `tools/site/i18n/<lang>.mjs`. Готовые файлы в `website/` коммитятся. Правка текста = правка словаря + пересборка.
- Шесть языков, как в приложении: en (по умолчанию), he, ru, yi, fr, es. Иврит и идиш — справа налево.
  Переводы he, yi, fr, es — машинные, ждут вычитки носителем.
- Писать только то, что приложение действительно умеет. Синхронизация — «когда человек открывает приложение, тянет список
  вниз, и раз в сутки в фоне», не «мгновенно».

## 2. Структура

```
website/
├── index.html, converter/, privacy/, family/  выбор языка по браузеру → /<lang>/… (см. §4)
├── <lang>/index.html                    главная
├── <lang>/converter/index.html          конвертер дат
├── <lang>/privacy/index.html            политика конфиденциальности
├── <lang>/family/index.html             «Общий семейный календарь»: общий список за 5 шагов со снимками (B-38)
├── sitemap.xml, robots.txt, favicon.svg
├── ledor-X.Y.Z.apk, ledor.apk           сборка для скачивания (не в git)
├── version.json                         номер последней версии Android из `apk-name.txt`; его читает кнопка «Проверить обновление» (`01`, ABT-5)
├── assets/css/styles.css                все стили
├── assets/js/hebrew-calendar.js         арифметика календаря (общая с тестами)
├── assets/js/converter.js               интерфейс конвертера; тексты — из <script id="i18n"> на странице
├── assets/js/site.js                    галерея и меню языков
├── assets/fonts/rubik.ttf               шрифт приложения (OFL), font-display: swap
├── assets/img/mark.svg, author-*.jpg, eco/, og/<lang>.png, screens/<lang>/*.png
└── tests/hebrew-calendar.test.mjs       JS-календарь на эталонных векторах spec/golden
```

`tools/site/`: `build.mjs` (шаблоны страниц, `ASSET_V` — номер версии ресурсов), `i18n/<lang>.mjs` (все тексты сайта и
конвертера), `apk-name.txt` (имя файла APK для ссылок), `og.mjs` (картинки-превью 1200×630).

## 3. Главная страница

Задача — представить приложение вокруг двух обещаний: **напоминает о датах** и **списком легко поделиться**.

1. **Шапка:** только логотип LeDor, выбор языка и «Скачать». Меню разделов нет.
2. **Первый экран:** знак, LeDor, слоган, **Kalendář**; заголовок «Напомнит о днях рождения и йорцайтах — всей семье»;
   кнопка «Скачать для Android» и неактивные плашки «Скоро в Google Play / App Store»; справа телефон с календарём,
   поверх него — уведомление и названия списков.
3. **Напоминания:** три пункта и макеты трёх уведомлений (накануне за 3 часа до заката, в день в 12:00, накануне йорцайта).
   Тексты макетов — те же, что показывает приложение.
4. **Общие списки:** экран списков → приглашение в WhatsApp/Telegram → события у родных; три шага; четыре пункта.
   Формулировка — «поделитесь списком» (в приглашении название и код доступа), а не «отправьте ПИН».
5. **И ещё:** шесть карточек (обе даты, йорцайт по правилам, бар/бат-мицва, батарея, языки, бесплатно и открыто).
6. **Скриншоты** в рамках телефона, прокрутка.
7. **Частые вопросы** (13) — с разметкой FAQPage.
8. **Блок скачивания.**
9. **Автор** (фото, «Гершон», канал в Telegram) и **«Другие проекты BotHub»** (не «экосистема»; BotHub — «нейросети без подписки»).
10. **Подвал:** Kalendář, ссылки: конвертер, частые вопросы, политика, удаление данных, GitHub, Telegram.

Конвертер и вопросы доступны только из подвала (и по своим адресам). Личный Telegram автора на сайте не указывается.

Плашки магазинов — собственные нейтральные (официальные значки нельзя перекрашивать); после публикации заменить на
официальные со ссылками, строку «Скоро» убрать, ответ про iPhone в вопросах — исправить.

## 4. Языки и адреса

- У каждого языка свой адрес: `/en/`, `/he/`, `/ru/`, `/yi/`, `/fr/`, `/es/` и такие же для `converter/`, `privacy/` и `family/`.
- Корень `/` и старые адреса `/converter/`, `/privacy/` — страница, которая по `navigator.languages` переходит на нужный язык
  (uk, be, kk → ru; иначе en) и запоминает выбор в `localStorage`; без JavaScript показывает список языков.
- Переключатель языка — в шапке каждой страницы.
- Приложение открывает сайт и политику на своём языке: `https://kalendar.bothub.chat/<locale_tag>/…`.

## 5. Конвертер

Отдельная страница `/<lang>/converter/`: григорианская ⇄ еврейская дата с переключателем «до/после захода», день недели,
ближайший еврейский день рождения, бар- и бат-мицва, йорцайт на 10 лет. На иврите и идише — даты буквами.
Логика — `hebrew-calendar.js`, проверяется `node --test website/tests/*.test.mjs` на всех эталонных векторах.
Подсказки «по времени и городу» (как в приложении) на сайте нет.

## 6. SEO

На каждой странице каждого языка: свои `<title>` и `description`, `<html lang dir>`, `canonical`, `hreflang` на все версии
и `x-default`, Open Graph и Twitter Card с картинкой `assets/img/og/<lang>.png`, JSON-LD (`MobileApplication`, `WebSite`,
`FAQPage`; у конвертера — `WebApplication`). `sitemap.xml` перечисляет все страницы с альтернативами.

## 7. Политика конфиденциальности

`/<lang>/family/` — текст в `i18n/<lang>.mjs` → `family`: вступление, пять шагов (создать список → поделиться → родные подключают) со снимками `10_lists`, `11_list_create`, `14_list_share`, `11b_list_join`, `05_events` и пять вопросов (`FAQPage`). Это главная особенность LeDor, поэтому ссылки на страницу — в шапке каждой страницы (на узких экранах скрыта), заметной кнопкой под первым абзацем главной, на карточке «Ваши списки» в первом экране, под разделом «Общие списки» и в подвале (решение заказчика 2026-11-26). Эту страницу удобно отправлять в ответ на вопрос «как видеть один календарь с женой».

`/<lang>/privacy/` — текст в `i18n/<lang>.mjs` → `privacy.body`. Двенадцать разделов: кто отвечает за данные, что хранится
только на телефоне, что на сервере (общие списки, отзывы, хэш IP), сроки (отзывы — 2 года, хэш IP — сутки, копии базы —
14 дней), правовые основания, кому передаются (хостинг-провайдер без названия — по просьбе заказчика хостинги на сайте не называются, D-59; Telegram для отзывов), права и удаление (`#delete`), дети,
изменения. Сейчас в тексте упоминается только Android — перед выходом iOS-версии дополнить.
Любое изменение в том, какие данные собирает приложение или сервер, сначала отражается здесь.

## 8. Сборка и выкладка

```bash
node tools/site/build.mjs                 # пересобрать страницы
node --test website/tests/*.test.mjs      # тесты календаря сайта
tools/deploy/publish.sh                   # тесты + rsync в /var/www/kalendar (без sudo)
```

- Сервер — Caddy, блок `tools/deploy/kalendar.caddy` (статика + API, см. `04-backend.md`). Перед ним — прокси-сервер,
  который пересылает запросы (D-58, `04-backend.md` §8); CDN с 26.11.2026 не используется.
- Картинки, стили и скрипты браузер кеширует (`/assets/*` — час). Поэтому: при изменении стилей, скриптов или картинок —
  увеличить `ASSET_V` в `build.mjs`; APK выкладывать под новым именем (`ledor-X.Y.Z.apk`) и обновить `apk-name.txt`.
- Снимки экранов берутся из приложения: `./gradlew :app:recordRoborazziDebug`, затем скопировать нужные файлы из
  `android/app/build/screens/<язык>/` в `website/assets/img/screens/<язык>/` (yi и he — тоже свои).
- Превью для соцсетей — `tools/site/og.mjs` (инструкция в начале файла).

## 9. Известные недоделки

- Тёмная тема сайта не просматривалась.
- Шрифт отдаётся как `ttf` (~360 КБ) — перевести в `woff2`.
- Нет страницы 404.
- Фото автора — одно, с лулавом в сукке (`author-lulav.jpg`, 720×720), вырезано из снимка экрана — при случае заменить оригиналом.
