## Как работать с планом

1. В начале сессии прочитать `CLAUDE.md`, затем документы, относящиеся к задаче (таблица в `CLAUDE.md`).
2. Порядок: тесты → код → проверка → запись в «Журнал» внизу этого файла.
3. Работа готова, когда:
   - проходит полная проверка: `source tools/env.sh && cd android && ./gradlew :domain:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`
     (для сайта — `node --test website/tests/*.test.mjs`, для iOS — тесты пакета `Domain` и сборка в симуляторе);
   - нет заглушек, `TODO` и строк интерфейса вне ресурсов;
   - для экранов — снимки сделаны и просмотрены;
   - документы обновлены: поведение — в `01`–`09`, решения — в `DECISIONS.md`, идеи заказчика — в `BACKLOG.md`.
4. Если документ противоречит коду — прав код; документ исправить.
5. Если не хватает ответа заказчика (раздел «Открытые вопросы» в `DECISIONS.md`) — взять значение по умолчанию и двигаться дальше.

## Ручная приёмка на реальном телефоне (выполняет заказчик)

Эмулятора на машине разработки нет, поэтому эти проверки — только на устройстве. Желательно Samsung + ещё один производитель.

- [ ] Холодный запуск: заставка LeDor ≈ 1.5 с, затем диалог импорта (только в первый раз); календарь открывается по еврейским месяцам.
- [ ] Создать событие с датой «завтра», выставить первое напоминание на «через 2 минуты» фиксированным временем → уведомление пришло при выключенном экране.
- [ ] То же после перезагрузки телефона (приложение не открывать).
- [ ] Телефон пролежал ночь без движения (режим Doze) → утреннее/дневное напоминание пришло вовремя.
- [ ] Отозвать разрешение на уведомления → появился баннер → «Исправить» ведёт в нужную настройку → после включения баннер исчез.
- [ ] Включить ограничение батареи для приложения → баннер появился; «Мне не нужны напоминания» → больше не появляется.
- [ ] Создать общий список, отправить приглашение в Telegram и WhatsApp → текст и ПИН верные.
- [ ] На втором телефоне подключить список обычным ПИНом → события видны, изменить нельзя.
- [ ] Ввести Мастер-ПИН → стало можно редактировать; правка появилась на первом телефоне после синхронизации.
- [ ] Режим полёта: добавить событие в общий список → значок «ожидает отправки» → после включения сети ушло.
- [ ] 5 раз ввести неверный ПИН → блокировка с понятным сообщением.
- [ ] Удалить список с сервера → на втором телефоне он исчез после синхронизации с сообщением.
- [ ] Событие «по обоим календарям» → в списке две строки в году, напоминания приходят для обеих дат.
- [ ] Подсказка «Не знаете?»: время и город → переключатель «до/после захода» выставился, в сумерках — предупреждение.
- [ ] «Отправить отзыв» → автор получил сообщение в Telegram.
- [ ] Сменить язык на иврит → экран зеркален, даты буквами; вернуть обратно.
- [ ] Через сутки-двое: в настройках батареи расход приложения в фоне ≈ 0 %.
- [ ] Тёмная тема, крупный шрифт, поворот экрана — ничего не ломается.
- [ ] Конвертер: 23.04.1990 → 28 Нисана 5750; «после захода» → 29 Нисана.
