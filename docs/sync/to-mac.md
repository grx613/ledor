## S-4 · 2026-11-26 · Android 0.6.4: выпуск в Google Play и три изменения для iOS

Статус: открыто

Заказчик посмотрел 0.6.3 на телефоне и попросил четыре вещи. Всё сделано в Android **0.6.4** (versionCode 13), код и документы в `main`.

### 1. Что изменилось

| Решение | Суть | iOS |
|---|---|---|
| D-51 | Возвращено системное окно «не экономить батарею» с одной кнопкой «Разрешить» (разрешение `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`). Заказчик принял риск, что Google отклонит выпуск | не касается |
| D-52 | Новое событие по умолчанию создаётся в облачном списке с правом редактирования (последний использованный из облачных, иначе первый по порядку); облачных нет — в «Личном» | **сделать** |
| D-53 | Список «Еврейские праздники» по умолчанию **выключен**. Переключатель на его карточке в «Списках» включает и выключает список целиком (раньше отключал только напоминания) | **сделать** |
| D-54 | Заменяет D-46: у каждого наступления снова **две даты** — главная крупно, под ней мелко тот же день в другом календаре | **сделать** |

### 3. То же в iOS

1. **Даты (D-54).** `occurrenceDates` снова всегда возвращает две даты. Наступление по еврейскому календарю — как было: первой календарь вкладки. Наступление по григорианскому — первой **всегда** григорианская («пт, 30 апреля 2027»), второй мелко еврейская дата того же дня («23 Нисана 5787»); заголовком строки она не бывает ни на одной вкладке. Карточка: «григорианская · еврейская» в обоих блоках. Редактор: «григорианская (еврейская)» в каждой строке «Ближайшее». Уведомление «в день события»: главная дата первой — у григорианского наступления «{григорианская} · {еврейская того же дня}. {возраст}». Образец — `DateFormatters.occurrenceDates` и `Reminders.kt`; текст — `docs/01` ALL-3, `docs/05` строка DAY.
2. **Список по умолчанию (D-52).** Образец — `defaultListId` в `EventEditorViewModel.kt`, примеры — тест `EditorDefaultsAndHealthTest.defaultListForNewEvent`; текст — `docs/01` EVT-2.
3. **Праздники (D-53).** По умолчанию выключены (`HolidaySettings.enabled = false`); переключатель на карточке в «Списках» = `enabled`. Под карточками подпись дополнена строкой `lists_hint_holidays` (6 языков в `strings.xml`). Текст — `docs/01` HOL-2.
